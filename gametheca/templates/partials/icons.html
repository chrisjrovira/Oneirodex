{# Oneirodex inline SVG icon set for Jinja templates. Mirrors frontend/member-app/src/chrome/icons.jsx so the Jinja pages and the member SPA speak one visual language: 24x24 viewBox, fill none, 2px stroke, round caps and joins, stroke="currentColor". Because every glyph inherits the surrounding text colour there are no per-icon colour rules to maintain and the icons re-theme automatically. Usage: {% import 'partials/icons.html' as icons %} {{ icons.icon('library') }} {{ icons.icon('cogs', size=28, extra_class='settings-shell-card-icon') }} {{ icons.icon('logout', title='Log out') }} `name` is a semantic key, not a Font Awesome class. Adding a glyph means adding one branch below; unknown names render a neutral dot so a typo can never blank out a layout. Pass `title` only when the icon is the sole label for a control; otherwise it stays aria-hidden so screen readers read the adjacent text once. #} {% macro icon(name, size=18, extra_class='', title='') -%} {%- endmacro %}
