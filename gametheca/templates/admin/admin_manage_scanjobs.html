The setting "Write Metadata File on Manual ID" is enabled in Server Settings, but GameTheca cannot write to the following path(s):

{% if session.get('permission_errors') %}
Failed Paths:
    {% for error in session['permission_errors'] %}
  • Path: {{ error.path }}
    Error: {{ error.error }}
    • {% endfor %}
{% endif %}
How to Fix:

You have two options:

  1. Fix Permissions (Recommended): Grant write permissions to the GameTheca user for the game folders: 
    sudo chmod -R u+w {{ session.get('permission_check_path', '/path/to/games') }}
    Or for the GameTheca user specifically: 
    sudo chown -R gametheca:gametheca {{ session.get('permission_check_path', '/path/to/games') }}
  2. Disable Feature: Go to Admin Dashboard → Manage Server Settings and turn off "Write Metadata File on Manual ID" under the "Local Metadata & Images" section.

{{ icons.icon('info') }} Note: Without write permissions, the local metadata feature cannot save game identification data to disk, and you won't get the benefits of surviving database resets.
