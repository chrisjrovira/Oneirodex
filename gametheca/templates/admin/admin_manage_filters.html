Two jobs, one list: strip junk from folder names, or skip whole folders during scans. Prefer Scan management → Scan Filters for the same UI.

How it works

  1. Name tag — plain text (e.g. GOG). Matcher strips -GOG / .GOG from folder basenames. Does not hide folders.
  2. Skip folder — dir: prefix (e.g. dir:_MyTools). Listing skips matching basenames (case-insensitive fnmatch).
  3. Prefix globs — prefer dolphin* / GOD v*, not *dolphin* / GOD*.
  4. Skip-dir is defense-in-depth — still use correct leaf library paths.
