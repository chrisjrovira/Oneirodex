## Quick verdict (updated)

| Need | Path |
|---|---|
| Presence / friends / profiles / Activity | **Native** (Waves 14+) |
| Text chat (DMs + household channels) | **Native mid** (Wave 15) |
| Voice / video / screenshare | **Optional LiveKit** sidecar (Wave 16) |
| Full Discord UX today | **BYO Stoat or Matrix** via `community_chat_url` |
| Library alerts | Discord **webhooks** (notify-only) |

**Do not** ship a Discord clone (bots platform, public guilds, Nitro). **Do** build household social that feels like Discord for a family/clan library.

See **[social-av.md](social-av.md)** for the Discord feature map, A/V best practices, and wave set.
