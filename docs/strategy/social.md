## Quick verdict (updated)

| Need | Path |
|---|---|
| Presence / friends / profiles / Activity | **Native** (shipped) |
| Text chat (DMs + household channels) | **Native** (shipped; mute + opt-in instant/digest email) |
| Voice / video / screenshare | **Optional LiveKit** sidecar (Wave 16 shipped) |
| Full-featured external chat | **BYO Stoat or Matrix** via `community_chat_url` |
| Library / support alerts | Native in-app notifications (+ GitHub Issues for tickets) |

**Do not** ship Discord webhooks or a bots platform.
