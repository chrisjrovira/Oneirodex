{{ icons.icon('palette', size=26) }} Creating Your Own Theme

Package a ZIP with theme.json + CSS at the archive root, then upload on Manage Themes.

Theme Structure

A theme consists of:

  • A ZIP file containing all theme files
  • A theme.json file with theme metadata
  • CSS files in a css folder
  • Optional image files in an images folder

theme.json Format

{
    "name": "Your Theme Name",
    "author": "Your Name",
    "description": "A brief description of your theme",
    "version": "1.0.0",
    "release_date": "YYYY-MM-DD"
}

CSS Files

Place CSS in the css folder. Main file: base.css. Additional files are structured by folder.

Creating the ZIP File

Important: The ZIP must contain theme files at the root level, not inside a subfolder.

  1. Create a folder with your theme name for organization
  2. Add the theme.json file to this folder
  3. Create a css subfolder and add your CSS files
  4. Optionally, create an images subfolder for theme-specific images
  5. When zipping, select the contents of your theme folder — do not zip the folder itself

Correct ZIP Structure

mytheme.zip
├── theme.json
├── css/
│   ├── base.css
│   ├── components.css
│   └── admin/
│       └── admin_dashboard.css
└── js/                ← optional
    └── custom.js

Incorrect ZIP Structure (will fail)

mytheme.zip
└── mytheme/           ← Extra folder layer causes upload to fail
    ├── theme.json
    ├── css/
    └── js/

Uploading Your Theme

Use the theme upload form on the Manage Themes page to upload your ZIP file.
